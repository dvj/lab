# Motor Skills Lab

A touch-friendly tracing page for kids to practice fine motor control on iPad (Mobile Safari) or any pointer-enabled browser. Open `index.html` to start, or host the folder with GitHub Pages.

## Features
- Story adventures only: guide jellyfish, squirrel, turtle, fox, otter, or hedgehog friends to safety
- "Stay inside the lines" mode that tints the guide glow if you drift out
- Adjustable ink color, pen width, and wider guide width control up to 64px (fixed glow)
- Randomized path variants on each selection and longer confetti when a clean trace connects start to finish
- Responsive layout tuned for iPad; canvas blocks page scroll while drawing

## GitHub Pages quick start
1. Commit this folder to your repo and push to GitHub.
2. In repository settings, enable **GitHub Pages** and choose the branch that contains `motor_skills/` with the folder as the site root.
3. The published URL will look like:
   - `https://<your-username>.github.io/<repo-name>/motor_skills/`
   - `https://<your-username>.github.io/motor_skills/` if you move the folder into its own repository.
4. Load the URL on an iPad and trace away.

## Local preview
Use any static server from the project root (for example `python -m http.server 8000`) and open `http://localhost:8000/motor_skills/`.
